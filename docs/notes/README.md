# Notes de développement

Notes de travail conservées pour mémoire : analyses, listes de tâches et
comptes rendus d'optimisation écrits au fil du développement. Elles décrivent
l'état du code **au moment où elles ont été écrites** et ne sont pas tenues à
jour.

La documentation de référence, elle, vit dans `docs/` :
[distribution](../distribution.md), [préférences et profils](../preferences-et-profils.md),
[tâches de fond](../async-tasks.md), [traductions](../translations.md).
