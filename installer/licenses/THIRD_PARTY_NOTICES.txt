MyGCFlow — composants tiers
========================

MyGCFlow redistribue les composants suivants. Chacun reste soumis à sa propre
licence.

FFmpeg (ffmpeg.exe)
-------------------
Build « essentials » 7.1 de gyan.dev, fourni par le paquet Python
imageio-ffmpeg. Ce build est configuré avec --enable-gpl --enable-version3 :
il est distribué sous licence GNU GPL version 3 (texte complet :
ffmpeg/COPYING.GPLv3.txt).

MyGCFlow appelle ffmpeg comme un programme séparé (ligne de commande), sans le
modifier.

Code source correspondant :
  - FFmpeg : https://ffmpeg.org/download.html (version 7.1)
  - Build et dépendances : https://www.gyan.dev/ffmpeg/builds/
  - imageio-ffmpeg : https://github.com/imageio/imageio-ffmpeg

Bibliothèques Python
--------------------
Les licences des paquets Python embarqués (Flask, SQLAlchemy, Pillow,
waitress, pystray…) sont copiées dans le dossier python/ lors de la
construction de l'exécutable.

Fonds de carte
--------------
Les tuiles cartographiques sont téléchargées à l'utilisation depuis les
serveurs de leurs fournisseurs et restent soumises à leurs conditions
d'utilisation (© OpenStreetMap contributors, etc.).
